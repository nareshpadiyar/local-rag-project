# Local RAG Test Datasource

This package contains synthetic, non-sensitive ACMECloud data designed to test a local RAG pipeline across multiple loaders.

Folders:
- PDF: PDF loader
- TXT: plain text loader
- CSV: CSV loader
- XLS: Excel loader
- SQL: SQL/text loader
- DOC: DOCX loader
- PPT: PowerPoint loader
- HTML: HTML loader
- JSON: JSON loader
- MD: Markdown loader

All names, emails, incidents, and infrastructure details are fictional.

See `RAG_TEST_PROMPTS.md` for validation prompts.
